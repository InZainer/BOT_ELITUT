# Инструкция для администратора

## Управление доступом к сауне

Доступ к гайду "Сауна" и активности "Сходить в баню" по умолчанию **заблокирован**.

### Как выдать доступ пользователю

Для выдачи доступа к сауне используйте команду:

```
/grant <user_id> sauna
```

Где `<user_id>` - это Telegram ID пользователя (отображается в сообщениях от консьержа).

**Пример:**
```
/grant 123456789 sauna
```

### Как отозвать доступ

Для отзыва доступа используйте команду:

```
/revoke <user_id> sauna
```

### Проверка доступа пользователя

Чтобы посмотреть все разрешения пользователя:

```
/permissions <user_id>
```

## Другие админ-команды

- `/ls` - посмотреть список файлов контента
- Ответить на сообщение пользователя: нажмите кнопку "✉️ Ответить" под сообщением от пользователя

## Добавление фото/видео к контенту

Используйте команды:
- `/set_photo <путь>` - затем отправьте фото
- `/set_video <путь>` - затем отправьте видео
- `/delete_photo <путь>` - удалить медиа

**Примеры путей:**
- `texts/house_rustic.md`
- `guides/fireplace.md`
- `guides/sauna.md`
